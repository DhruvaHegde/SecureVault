# 🔐 SecureVault

A full-stack Password Manager built using Spring Boot, React, JWT Authentication, and MySQL.

## 🚀 Features

- User Registration
- Secure Login using JWT
- Add Password
- View Saved Passwords
- Search Passwords
- Update Password
- Delete Password
- Password Strength Checker
- Password Generator
- AES Password Encryption
- Responsive Dashboard

## 🛠️ Tech Stack

### Backend
- Java 25
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL

### Frontend
- React
- Vite
- Axios
- Tailwind CSS

## ▶️ Run Backend

```bash
mvn spring-boot:run
```

Runs on:

```
http://localhost:8081
```

## ▶️ Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on:

```
http://localhost:5173
```
